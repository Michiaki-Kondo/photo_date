# Photo Date

iPhone の写真に、フィルムカメラ風のオレンジ色の日付を刻印する SwiftUI アプリです。iOS 17 以降に対応します。

## 使い方

1. 「写真を選ぶ」で1〜20枚選択します。
2. 撮影日とプレビューを確認し、左下・右下を選択します。日付は個別に変更できます。
3. 「日付入りで保存」で新しい JPEG 画像を写真ライブラリに保存します。

刻印は `2026.10.19` 形式です。EXIF の撮影日、デジタル化日時、TIFF の日時の順に調べ、なければ写真ライブラリの作成日を取得します。ライブラリの日付取得には写真アクセスの許可が必要です。制限付きアクセスでは対象写真を許可してください。取得できない場合は日付を手動で指定します。撮影メタデータの日付は撮影場所の暦日を維持します。写真ライブラリの作成日は端末のタイムゾーンで解釈します。

元画像は変更しません。処理は端末内で完結し、外部サーバー・APIキー・外部依存パッケージは不要です。Live Photos、動画、RAW の保持・書き出しには対応せず、読み込める静止画を JPEG として保存します。書き出しは表示方向を反映した標準色域の画像で、元の EXIF、位置情報、HDR 表現は引き継ぎません。大量の高解像度写真はメモリを使うため、少数ずつ処理してください。

## 開発・起動

Mac と Xcode 15 以降が必要です。

1. `PhotoDate.xcodeproj` を Xcode で開きます。
2. 実機の場合はターゲットの Signing & Capabilities で自身の Team と固有の Bundle Identifier を設定します。
3. iOS 17 以降の iPhone またはシミュレーターを選択し、Run を実行します。

署名不要のシミュレータービルド:

```sh
cd /path/to/photo_date
xcodebuild -project PhotoDate.xcodeproj -scheme PhotoDate \
  -sdk iphonesimulator -configuration Debug CODE_SIGNING_ALLOWED=NO build
```

## 動作確認項目

- EXIF 撮影日付き写真の刻印が撮影日と一致すること。端末のタイムゾーンを変えても EXIF の暦日が変わらないこと。
- スクリーンショットの作成日を取得できること。許可拒否・制限付きアクセス・日付なしでは手動指定で保存できること。
- 複数選択、個別の日付修正、左右の位置変更が書き出しに反映されること。
- 縦横・回転付き画像が正しい向きで保存され、元の写真が変更されないこと。
- 写真追加の許可拒否時に案内が表示され、許可後に保存できること。
- iCloud 写真の取得失敗、容量不足、部分的な保存失敗で結果が表示されること。
